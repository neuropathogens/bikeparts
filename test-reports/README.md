# Physical test reports (Gate 3)

One folder per part: `test-reports/<part>/<YYYY-MM-DD>-<test>.md` plus photos.
Mark every bolt head with a paint line before testing so loosening is visible.

Template:

```
Part / preset:
Test:                 (bolt torque | rotational slip | heat soak | ride vibration | drop | ...)
Date:
Printer:
Filament (brand, type, color, dried?):
Profile:              profiles/<material>.ini @ <git sha>
Orientation:          as exported (+Z build)
Method:
Result:               PASS | FAIL
Observations:
Photos:
```
